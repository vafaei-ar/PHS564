# Capstone Project Submission Checklist

Before submitting your final project, verify:

## Required Files

- [ ] `project/protocol.md` (final version)
- [ ] `project/notebooks/analysis.ipynb` (runs end-to-end)
- [ ] `project/report.md` (≤6 pages)
- [ ] `project/results/` (tables/figures)

## Content Checklist

- [ ] Target trial protocol is complete and implementable
- [ ] Time zero is unambiguous
- [ ] Eligibility criteria are implementable
- [ ] Confounder list is justified clinically
- [ ] Estimator is appropriate and correctly implemented
- [ ] Diagnostics are included (positivity, weights, balance, or model fit)
- [ ] Results are clearly presented (table + figure)
- [ ] Limitations are honestly discussed
- [ ] Assumptions are explicitly stated

## Technical Checklist

- [ ] Notebook runs top-to-bottom without errors
- [ ] All code cells execute successfully
- [ ] Figures are saved and readable
- [ ] Random seeds are set for reproducibility
- [ ] No patient-level data is committed to Git

## Presentation Checklist

- [ ] Presentation is 5–6 minutes
- [ ] All required slides are included
- [ ] Key findings are clearly communicated
- [ ] Limitations are discussed

---

**Submission:** Submit via GitHub (final PR or release tag) and Canvas as instructed.
