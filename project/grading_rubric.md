# Capstone Project Grading Rubric

**Total: 100 points**

## Protocol (20 points)

- **Completeness (10 pts):** All required elements present and clearly defined
- **Implementability (10 pts):** Protocol can be executed with available data

## Analysis (30 points)

- **Reproducibility (15 pts):** Notebook runs end-to-end without errors
- **Correctness (15 pts):** Appropriate methods, correct implementation

## Report (30 points)

- **Clarity (10 pts):** Well-written, clear structure
- **Completeness (10 pts):** All required sections present
- **Honesty (10 pts):** Limitations clearly stated, assumptions discussed

## Presentation (20 points)

- **Content (10 pts):** Clear, engaging, covers key points
- **Delivery (10 pts):** Within time limit, professional

## Bonus Points (up to +10)

- Exceptional clarity or innovation
- Advanced methods (if appropriate)
- Outstanding teamwork

---

## Grade Scale

- A: 90-100
- B: 80-89
- C: 70-79
- D: 60-69
- F: <60
