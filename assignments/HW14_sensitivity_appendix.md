# Homework 14: Robustness and sensitivity: unmeasured confounding, negative controls

**Team-based assignment** (2-person teams)

## Instructions

Complete the following tasks using the sensitivity toolkit from L14:
1. Add robustness appendix to your project repo
2. Submit updated repo

---

## Tasks

### 1. Sensitivity analysis

Add one sensitivity analysis to your project:
- E-value (RR scale; OR requires an approximation—label clearly) or
- Bias-factor sensitivity

### 2. Negative control proposal

Propose one negative control (exposure or outcome) and justify:
- Why it should be affected by similar confounding
- Why it should not be affected by treatment (for NCO) or not affect outcome (for NCE)

### 3. "What would change our conclusion?"

Write one paragraph: what would change our conclusion?

---

## Deliverables

Add to project repo:
- `robustness.md` appendix with:
  - One sensitivity analysis
  - One negative control proposal + justification
  - One "what would change our conclusion?" paragraph

## Submission

Submit via GitHub PR (update to project repo).

## Grading Rubric

- Sensitivity analysis (40%): Correct computation, clear interpretation
- Negative control (40%): Relevant, well-justified
- Conclusion paragraph (20%): Thoughtful, honest
